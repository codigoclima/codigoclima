Como o CódigoClima funciona

1. Digite o código exibido pelo aparelho.

2. Confira a marca e o modelo, porque o mesmo código pode ter significados diferentes.

3. Consulte o significado, possíveis causas e verificações iniciais.

4. Quando houver risco elétrico, necessidade de abrir o equipamento ou intervenção no circuito de refrigeração, procure assistência qualificada.

Importante: este site é um guia informativo independente. Códigos podem variar entre modelos e gerações. Sempre confirme as informações no manual específico do aparelho ou com o fabricante antes de realizar qualquer intervenção.
